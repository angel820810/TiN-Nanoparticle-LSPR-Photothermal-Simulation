# TiN-Nanoparticle-LSPR-Photothermal-Simulation
***** Download the presentation from the [latest release](https://github.com/angel820810/TiN-Nanoparticle-LSPR-Photothermal-Simulation/releases/latest). *****

An independent computational study extending my master's research on plasmonic nanoparticles. Using Python, Meep 3D FDTD, and steady-state thermal modeling, this project investigates how TiN nanoparticle geometry, polarization, and dielectric environment influence field enhancement, optical absorption, and photothermal heating.


*Research Workflow

Fit a Lorentz–Drude model to published TiN optical data.

Use Meep 3D FDTD to evaluate geometry- and polarization-dependent field enhancement and absorption.

Calculate optical heat generation and steady-state temperature rise.

**Project Presentation

The accompanying presentation describes the research motivation, physical models, simulation conditions, results, and comparison with published literature.
